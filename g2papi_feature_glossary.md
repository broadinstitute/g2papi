# Genomics 2 Proteins (G2P) Protein Features - Data Dictionary

This document provides a comprehensive, field-by-field description of the protein feature dataset generated by the **Genomics 2 Proteins (G2P) portal** (developed by the Broad Institute). The dataset integrates residue-level protein feature annotations; the data dictionary below lists every column with its meaning, expected values, and data type.

## Overview of Dataset Structure

The G2P protein feature table has one row per amino acid position of a canonical protein isoform. Its columns are grouped into the eight feature modules below:

| **\#** | **Group** | **Contents** | **Count** |
|---|---|---|---|
| 1 | Residue identity & physicochemical properties | Basic sequence positioning and amino acid characteristics, plus quantitative physical metrics including molar mass and hydropathy scales | 6 |
| 2 | 3D structural features | Precomputed structural features: secondary structure, surface accessibility, backbone dihedral angles, and structural prediction confidence | 7 |
| 3 | UniProt sequence annotations | Curated sequence annotations detailing domains, active sites, binding regions, signals, and sequence variants from UniProtKB | 31 |
| 4 | Post-translational modifications | Experimental and predicted modification types, regulatory sites, disease relevance, and substrate associations from PhosphoSitePlus | 11 |
| 5 | Druggability features (binding pocket predictions) | Binding pocket and druggability predictions from fpocket, AF2Bind, and P2Rank | 6 |
| 6 | Protein interaction features | Intra-chain (8) and inter-chain (4) covalent and non-covalent interactions from PDB and AlphaFold2 | 12 |
| 7 | Protein feature enrichment scores (PFES) | A score quantifying feature-level enrichment for missense mutations within pathogenic variants | 7 |
| 8 | Variant effects (MAVEs) | Multiplexed Assay of Variant Effects (MAVEs) from MaveDB | 2 per score set |

### 1. Residue identity & physicochemical properties
| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **residueId** | Integer index of the amino acid residue along the primary protein sequence, ranging from 1 to N (protein length) | Integer |
| **AA** | Single-letter IUPAC amino acid code | String |
| **Amino acid residues** | Full standard name of the amino acid residue | String |
| **Amino acid properties** | Qualitative classification of side-chain physicochemical properties (Aliphatic, Aromatic, Polar/neutral, Positively-charged, Negatively-charged, Special) | String |
| **Molar mass (g/mol)** | Molecular mass of the individual amino acid residue in grams per mole, ranging from 75 (Glycine) to 204 (Tryptophan) | Integer |
| **Hydropathy** | Kyte-Doolittle hydropathy index score (positive values indicate hydrophobic, negative indicate hydrophilic), ranging from -4.5 to 4.5 | Float |

### 2. 3D structural features

Columns marked `*` are computed from AlphaFold2 predicted structures; treat them with caution where pLDDT is low. 

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **Secondary structure (PDBe/SIFTS)** | Secondary structure assignment imported from experimental PDB structures via PDBe/SIFTS (Helix, Beta strand, Turn, Loop). Empty if no secondary structure assigned. | String |
| **Secondary structure (DSSP 3-state)\*** | Simplified 3-state secondary structure classification calculated by DSSP (H: Helix, E: Strand, C: Loop/Coil) | String |
| **Secondary structure (DSSP 9-state)\*** | Detailed 9-state secondary structure mapping derived via DSSP algorithms (H: α-helix, G: 3-10 helix, I: π-helix, P: polyproline helix, E: extended strand, B: β-bridge, T: turn, S: bend, C: loop/coil) | String |
| **Accessible surface area (Å²)\*** | Solvent accessible surface area (ASA) of the residue side-chain and backbone measured in Å² via DSSP, ranging from 85 to 315 | Integer |
| **Phi angle (degrees)\*** | Backbone dihedral torsion angle Phi (φ) around the N-Cα bond, ranging from -180 to 180 degrees | Float |
| **Psi angle (degrees)\*** | Backbone dihedral torsion angle Psi (ψ) around the Cα-C bond, ranging from -180 to 180 degrees | Float |
| **AlphaFold confidence (pLDDT)** | Per-residue predicted Local Distance Difference Test (pLDDT) score from AlphaFold2 (higher indicates higher structural confidence), ranging from 0 to 100 | Float |

### 3. UniProt sequence annotations

These columns copy curated UniProtKB sequence features onto every residue the feature spans, so a feature spanning many residues repeats the same value on each of its rows. Each value is description is UniProt's free-text annotation.

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **Active site** | Residues directly involved in catalytic activity or enzymatic reactions | String |
| **Binding site** | Binding sites for chemical ligands, ions, substrate molecules, or cofactors | String |
| **Chain** | Extent of the mature polypeptide chain after processing of precursor signals or propeptides | String |
| **Coiled coil** | Positions participating in coiled-coil structural domains | String |
| **Compositional bias** | Regions enriched in specific amino acid types | String |
| **Cross-link** | Covalent linkage between specific amino acid residues | String |
| **Disulfide bond** | Intra- or inter-chain covalent disulfide bonds formed between cysteine residues | String |
| **DNA binding** | Residues directly involved in interacting with DNA molecules | String |
| **Domain** | Defined modular protein domain boundaries as annotated in UniProtKB | String |
| **Glycosylation** | Covalently attached sugar moieties | String |
| **Initiator methionine** | Cleavage or retention of the initial N-terminal methionine residue | String |
| **Intramembrane** | Residues embedded within a lipid membrane without spanning it entirely | String |
| **Lipidation** | Covalent attachment of lipid groups | String |
| **Modified residue** | Post-translationally modified amino acids | String |
| **Motif** | Short sequence motifs of biological interest | String |
| **Mutagenesis** | Experimental mutagenesis data detailing amino acid substitutions and functional effects | String |
| **Non-adjacent residues** | Residues that are not consecutive in sequence but connected due to splicing or edit variations | String |
| **Non-standard residue** | Non-standard amino acids incorporated into the chain | String |
| **Non-terminal residue** | Residues known to not be N- or C-terminal, indicating sequence fragmentation | String |
| **Peptide** | Active small cleavage peptides generated from a precursor protein | String |
| **Propeptide** | Propeptide segment cleaved off during protein maturation | String |
| **Region** | Functional or structural region of interest | String |
| **Repeat** | Internal sequence repeats within the protein structure | String |
| **Sequence conflict** | Discrepancies reported across different sequence databases or literature sources | String |
| **Sequence uncertainty** | Regions of uncertain sequence determination in experimental data | String |
| **Signal** | N-terminal signal peptide directing intracellular trafficking or secretion | String |
| **Site** | Any single-residue site of interest not covered by other specific categories | String |
| **Topological domain** | Subcellular location of protein domains relative to membranes | String |
| **Transit peptide** | Targeting sequence directing proteins to organelles | String |
| **Transmembrane** | Transmembrane helical or strand region spanning the lipid bilayer | String |
| **Zinc finger** | Small functional domain stabilized by bound zinc ions | String |

### 4. Post-translational modifications

Most PTM cells are text records with labeled fields separated by semicolons (e.g., Morphology: ALGAEIVrtPtNARF; Domain: PALP). `Morphology` is the local sequence window around the site (typically 15 residues); lowercase letters mark modified residues. `Domain` names the domain that contains the site. All 11 columns in this group are strings, and empty cells mean no site is annotated.

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **Acetylation** | Lysine or N-terminal acetylation sites sourced from high-throughput PTM databases | String |
| **Disease-associated PTMs** | Post-translational modifications annotated as functionally linked to pathological conditions | String |
| **Methylation** | Arginine or lysine methylation modifications | String |
| **O-GalNAc** | Oxygen-linked N-Acetylgalactosamine glycosylation sites and sequence morphology | String |
| **O-GlcNAc** | Oxygen-linked N-Acetylglucosamine modifications on serine/threonine residues | String |
| **Phosphorylation** | Phosphorylation sites (Ser/Thr/Tyr) with local sequence morphology and domain context | String |
| **SNP-associated PTMs** | Single Nucleotide Polymorphisms (SNPs) that overlap with or disrupt PTM sites | String |
| **Regulatory sites** | PTM locations known to exert explicit molecular switches or regulatory control | String |
| **Substrate genes** | Target substrate genes involved in downstream modifying interactions | String |
| **SUMOylation** | Small Ubiquitin-like Modifier (SUMO) conjugation sites | String |
| **Ubiquitination** | Ubiquitin covalent attachment sites along lysine residues | String |

### 5. Druggability features (binding pocket predictions)

Three tools predict ligand-binding pockets on the AlphaFold2 structure: fpocket, af2bind and p2rank. Each tool has a pair of columns: a pocket record (identifier plus supporting details) and the numeric score for that pocket. Residues outside any predicted pocket are empty. All six columns are marked `*`, so interpret them with caution where pLDDT is low. The pocket-number columns are strings; the score and probability columns are floats.

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **fpocket: pocket number\*** | Pocket identifier calculated by fpocket geometry algorithm along with mean pLDDT (0 to 100) and pocket volume (\>0 Å³); pocket rank ranges from 1 to N, where 1 is the most druggable | String |
| **fpocket: druggability score\*** | Quantitative druggability score computed by fpocket indicating pocket suitability for small molecule binding, ranging from 0 to 1 | Float |
| **af2bind: pocket number\*** | Binding pocket identifier predicted by af2bind with mean pLDDT (0 to 100) and binding probability for the pocket; pocket rank ranges from 1 to N | String |
| **af2bind: binding probability\*** | Ligand binding probability assigned by af2bind to the local surface pocket, ranging from 0 to 100% | Float |
| **p2rank: pocket number\*** | Binding pocket identifier predicted by machine-learning tool p2rank with local probability and mean pLDDT (0 to 100); pocket rank ranges from 1 to N | String |
| **p2rank: pocket probability\*** | Ligand binding probability assigned by p2rank models to the local surface pocket, ranging from 0 to 1 | Float |

### 6. Protein interaction features

Each cell lists the residue pairs in contact, written as `residue-partner` (e.g., E31-S41), on the row of the first residue named. Several pairs are separated by commas. Two evidence sources are used. Values from experimental structures end with the supporting PDB entries, e.g., `(PDBs: 1F5Y)`. Values from AlphaFold2 models end with the Predicted Aligned Error (PAE) for the pair, e.g., `(PAE: 2.0)`; lower PAE means higher confidence in the relative position of the two residues. Inter-chain pairs prefix each residue with its chain (e.g., `D:F86-A:R375`) and come only from PDB complexes. All 12 columns in this group are strings, and a cell is empty when no contact is recorded.

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **Intra-chain Hydrogen bond (PDB)** | Intra-chain hydrogen bonds observed in experimental PDB structures (with target residue and PDB ID) | String |
| **Intra-chain Hydrogen bond (AlphaFold2)** | Intra-chain hydrogen bonds predicted from AlphaFold2 structures with Predicted Aligned Error (PAE) scores | String |
| **Intra-chain Non-bonded interaction (PDB)** | Intra-chain non-covalent contacts (van der Waals, hydrophobic packing) from experimental PDB structures | String |
| **Intra-chain Non-bonded interaction (AlphaFold2)** | Predicted intra-chain non-bonded contacts derived from AlphaFold2 structural models | String |
| **Intra-chain Disulfide bond (PDB)** | Experimental intra-chain covalent disulfide bridges identified in resolved PDB entries | String |
| **Intra-chain Disulfide bond (AlphaFold2)** | Predicted intra-chain disulfide bonds based on proximity in AlphaFold2 models | String |
| **Intra-chain Salt bridge (PDB)** | Intra-chain electrostatic ionic salt bridges (e.g., Lys/Arg to Asp/Glu) resolved in PDB | String |
| **Intra-chain Salt bridge (AlphaFold2)** | Predicted intra-chain ionic salt bridges modeled in AlphaFold2 structures | String |
| **Inter-chain Hydrogen bond (PDB)** | Hydrogen bonds formed across distinct polypeptide chains in multi-protein complexes | String |
| **Inter-chain Non-bonded interaction (PDB)** | Non-covalent hydrophobic and van der Waals interactions across complex chain interfaces | String |
| **Inter-chain Disulfide bond (PDB)** | Inter-chain covalent disulfide linkage between separate subunits or binding partners | String |
| **Inter-chain Salt bridge (PDB)** | Inter-chain ionic salt bridge interactions present at complex interfaces | String |

### 7. Protein feature enrichment scores (PFES)

The Protein Feature Enrichment Score (PFES) framework measures the localized statistical enrichment or depletion of protein features among established pathogenic variants. Each value is the mean score averaged over the 19 possible amino acid substitutions at the reference position. For a variant-specific score, use the [PFES page](https://g2p.broadinstitute.org/pfes). PFES is the overall score; the six sub-scores cover one context each and are empty for residues that have no annotation in that context. All seven columns are floats; scores are unbounded, and higher values indicate stronger enrichment.

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **PFES** | Overall composite Protein Feature Enrichment Score combining multi-dimensional structural and functional annotations | Float |
| **PFES_Physicochemical** | Sub-score evaluating variant enrichment relative to amino acid physicochemical shifts (mass, polarity, hydropathy) | Float |
| **PFES_Structure** | Sub-score quantifying enrichment at structural microenvironments (secondary structures, burial depth, pLDDT) | Float |
| **PFES_Domain** | Sub-score assessing variant clustering within specific UniProt structural and functional domain boundaries | Float |
| **PFES_Function** | Sub-score reflecting variant enrichment at annotated active sites, binding pockets, and functional regions | Float |
| **PFES_Modification** | Sub-score measuring variation impact at post-translational modification (PTM) sites | Float |
| **PFES_PPI** | Sub-score assessing variant enrichment within Protein-Protein Interaction (PPI) interface surfaces | Float |

### 8. Variant effect (MAVEs)

Each MaveDB score set contributes two columns, placed at the end of the file after PFES. The column names are built from the MaveDB score set ID (marker ⁺), for example 00000005-a-1. Replace \<ID\> below with the score set ID. The outliers column is a string; the avg column is a float.

| **Feature (Column Name)** | **Description** | **Data type** |
|---|---|---|
| **\<ID\> outliers⁺⁺** | Individual variants at this residue scoring in the top or bottom 99th percentile of the score set (marker ⁺⁺), each written as an amino acid change with its score (Ter = stop codon); empty when no such variant exists | String |
| **\<ID\> avg** | Average MAVE score at this residue, on the assay-defined score scale (see the score set on MaveDB) | Float |
