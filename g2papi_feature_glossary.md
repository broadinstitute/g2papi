# **Genomics 2 Proteins (G2P) Feature File Specification & Data Dictionary**

---

This document provides a comprehensive, field-by-field description of the protein feature dataset generated by the **Genomics 2 Proteins (G2P) portal** (developed by the Broad Institute). The dataset integrates residue-level protein feature annotations and the data dictionary below lists every column with its meaning, data type, and an example value.

## **Overview of Dataset Structure**

The G2P protein feature table contains **protein features from 9 feature groups (columns)** per amino acid position (row) for a given protein isoform. The columns are systematically categorized into eight distinct functional modules:

| \# | Group | Columns | Count |
| :---- | :---- | :---- | :---- |
| 1 | Residue identity & basic properties | Basic sequence positioning and amino acid characteristics. | 4 |
| 2 | Physicochemical properties | Quantitative physical metrics including molar mass and hydropathy scales. | 2 |
| 3 | 3D structural features | Secondary structure, surface accessibility, backbone dihedral angles, and structural prediction confidence. | 7 |
| 4 | UniProt sequence annotations | Curated sequence annotations detailing domains, active sites, binding regions, signals, and sequence variants (all marked “(UniProt)”) | 31 |
| 5 | Post-translational modifications (PTMs) | Experimental and predicted modification types, regulatory sites, disease relevance, and substrate associations. | 11 |
| 6 | Druggability features (binding pocket predictions) | Computational identification of binding pockets and druggability predictions. | 6 |
| 7 | Protein Interaction Features (residue-wise structural contacts) | Intra-chain (8) and inter-chain (4) covalent and non-covalent interactions from PDB and AlphaFold2 | 12 |
| 8 | Protein Feature Enrichment Scores (PFES) | A score quantifying feature-level enrichment for missense mutations within pathogenic variants | 7 |
| 9 | MAVE data (MaveDB) | Multiplexed Assay of Variant Effects (MAVEs) from MaveDB. | 2 per score set |

## **Detailed Feature (Column) Data Dictionary**

### **1\. Residue Identity & Basic Properties**

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **residueId** | 1-based position integer index of the amino acid residue along the primary protein sequence. | Integer (e.g., 1, 27\) |
| **AA** | Single-letter IUPAC amino acid code representing the residue at the specified position. | String (e.g., M, C) |
| **Amino acid residues** | Full standard name of the amino acid residue corresponding to the single-letter code. | String (e.g., Methionine, Cysteine) |
| **Amino acid properties** | Qualitative classification of side-chain physicochemical properties | String (e.g., Aliphatic) |

### **2\. Structural Features (DSSP, SIFTS, & AlphaFold)**

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **Secondary structure (PDBe/SIFTS)** | Secondary structure assignment imported from experimental PDB structures via the PDBe/SIFTS (fetched from UniProtKB)  | String (e.g., Beta strand) |
| **Secondary structure (DSSP 3-state)\*** | Simplified 3-state secondary structure classification calculated by DSSP (H: Helix, Strand \[E\], Loop/Coil \[C\]). Asterisk denotes computation from model/structure. | String (e.g.) H (helix), E (strand)) |
| **Secondary structure (DSSP 9-state)\*** | Detailed 9-state secondary structure mapping derived via DSSP algorithms (alpha helix, 3-10 helix, pi helix, extended strand, beta bridge, turn, bend, loop/coil). | String (e.g., C (loop/coil), H (alpha-helix)) |
| **Accessible surface area (Å²)\*** | Solvent accessible surface area (ASA) of the residue side-chain and backbone measured in square Ångströms via DSSP. | Numeric / Float (e.g., 249, 77\) |
| **Phi angle (degrees)\*** | Backbone dihedral torsion angle Phi (φ) around the N-Cα bond, measured in degrees. | Float (e.g., 360.0, \-116.5) |
| **Psi angle (degrees)\*** | Backbone dihedral torsion angle Psi (ψ) around the Cα-C bond, measured in degrees. | Float (e.g., 113.6, 146.7) |
| **AlphaFold confidence (pLDDT)** | Per-residue predicted Local Distance Difference Test (pLDDT) score from AlphaFold2, ranging from 0 to 100 (higher indicates higher structural confidence). | Float (e.g., 39.34, 92.51) |

### **3\. UniProtKB Functional Annotations**

These columns map curated annotations from the UniProt Knowledgebase (UniProtKB) to each specific residue position:

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **Active site (UniProt)** | Residues directly involved in catalytic activity or enzymatic reactions. | String / Categorical |
| **Binding site (UniProt)** | Binding sites for chemical ligands, ions, substrate molecules, or cofactors. | String |
| **Chain (UniProt)** | Extent of the mature polypeptide chain after processing of precursor signals or propeptides. | String (e.g., Low-density lipoprotein receptor) |
| **Coiled coil (UniProt)** | Positions participating in coiled-coil structural domains. | String |
| **Compositional bias (UniProt)** | Regions enriched in specific amino acid types (e.g., polar-rich or proline-rich regions). | String (e.g., Polar residues) |
| **Cross-link (UniProt)** | Covalent linkage between specific amino acid residues (e.g., transglutaminase cross-links). | String |
| **Disulfide bond (UniProt)** | Intra- or inter-chain covalent disulfide bonds formed between cysteine residues. | String (e.g., Disulfide bond 27-39) |
| **DNA binding (UniProt)** | Residues directly involved in interacting with DNA molecules. | String |
| **Domain (UniProt)** | Defined modular protein domain boundaries as annotated in UniProtKB. | String (e.g., LDL-receptor class A 1\) |
| **Glycosylation (UniProt)** | Covalently attached sugar moieties (N-linked, O-linked, or C-linked glycosylation sites). | String (e.g., N-linked (GlcNAc...) asparagine) |
| **Initiator methionine (UniProt)** | Cleavage or retention of the initial N-terminal methionine residue. | String |
| **Intramembrane (UniProt)** | Residues embedded within a lipid membrane without spanning it entirely. | String |
| **Lipidation (UniProt)** | Covalent attachment of lipid groups (e.g., myristoylation, palmitoylation, prenylation). | String |
| **Modified residue (UniProt)** | Post-translationally modified amino acids (e.g., phosphothreonine, acetylated lysine). | String (e.g., Phosphothreonine) |
| **Motif (UniProt)** | Short sequence motifs of biological interest (e.g., endocytosis signaling sequence). | String (e.g., NPXY motif) |
| **Mutagenesis (UniProt)** | Experimental mutagenesis data detailing amino acid substitutions and functional effects. | String (e.g., Mutation: W \-\> I...) |
| **Non-adjacent residues (UniProt)** | Residues that are not consecutive in sequence but connected due to splicing or edit variations. | String |
| **Non-standard residue (UniProt)** | Non-standard amino acids incorporated into the chain (e.g., selenocysteine). | String |
| **Non-terminal residue (UniProt)** | Residues known to not be N- or C-terminal, indicating sequence fragmentation. | String |
| **Peptide (UniProt)** | Active small cleavage peptides generated from a precursor protein. | String |
| **Propeptide (UniProt)** | Propeptide segment cleaved off during protein maturation. | String |
| **Region (UniProt)** | Functional or structural region of interest (e.g., protein-protein interaction region). | String (e.g., Binding to Getah virus...) |
| **Repeat (UniProt)** | Internal sequence repeats within the protein structure. | String (e.g., LDL-receptor class B 1\) |
| **Sequence conflict (UniProt)** | Discrepancies reported across different sequence databases or literature sources. | String (e.g., in Ref. 4; BAG58495) |
| **Sequence uncertainty (UniProt)** | Regions of uncertain sequence determination in experimental data. | String |
| **Signal (UniProt)** | N-terminal signal peptide directing intracellular trafficking or secretion. | String (e.g., Signal) |
| **Site (UniProt)** | Any single-residue site of interest not covered by other specific categories. | String |
| **Topological domain (UniProt)** | Subcellular location of protein domains relative to membranes (e.g., Extracellular, Cytoplasmic). | String (e.g., Extracellular, Cytoplasmic) |
| **Transit peptide (UniProt)** | Targeting sequence directing proteins to organelles (e.g., mitochondria, chloroplasts). | String |
| **Transmembrane (UniProt)** | Transmembrane helical or strand region spanning the lipid bilayer. | String (e.g., Helical) |
| **Zinc finger (UniProt)** | Small functional domain stabilized by bound zinc ions. | String |

### **4\. Physicochemical Properties**

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **Molar mass (g/mol)** | Molecular mass of the individual amino acid residue in grams per mole. | Float / Integer (e.g., 149, 75\) |
| **Hydropathy** | Kyte-Doolittle hydropathy index score (positive values indicate hydrophobic, negative indicate hydrophilic). | Float (e.g., 1.9, \-0.4) |

### **5\. Post-Translational Modifications (PTMs)**

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **Acetylation** | Lysine or N-terminal acetylation sites sourced from high-throughput PTM databases. | String |
| **Disease-associated PTMs** | Post-translational modifications annotated as functionally linked to pathological conditions. | String |
| **Methylation** | Arginine or lysine methylation modifications. | String |
| **O-GalNAc** | Oxygen-linked N-Acetylgalactosamine glycosylation sites and sequence morphology. | String (e.g., Morphology: EAEAAVAtQEtstVR) |
| **O-GlcNAc** | Oxygen-linked N-Acetylglucosamine modifications on serine/threonine residues. | String |
| **Phosphorylation** | Phosphorylation sites (Ser/Thr/Tyr) with local sequence morphology and domain context. | String (e.g., Morphology: GCPPKTCsQDEFRCH...) |
| **SNP-associated PTMs** | Single Nucleotide Polymorphisms (SNPs) that overlap with or disrupt PTM sites. | String (e.g., dbSNP: rs13306510; Variant: Pro105Ser) |
| **Regulatory sites** | PTM locations known to exert explicit molecular switches or regulatory control. | String |
| **Substrate genes** | Target substrate genes involved in downstream modifying interactions. | String |
| **SUMOylation** | Small Ubiquitin-like Modifier (SUMO) conjugation sites. | String |
| **Ubiquitination** | Ubiquitin covalent attachment sites along lysine residues. | String (e.g., Morphology: EFQCQDGkCISYKWV...) |

### **6\. Pocket Annotations (fpocket & p2rank)**

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **fpocket: pocket number\*** | Pocket identifier calculated by fpocket geometry algorithm along with mean pLDDT and pocket volume. | String (e.g., Pocket 4: Mean pLDDT: 85.58...) |
| **fpocket: druggability score\*** | Quantitative druggability score (0 to 1\) computed by fpocket indicating pocket suitability for small molecule binding. | Float (e.g., 0.0541) |
| **p2rank: pocket number\*** | Binding pocket identifier predicted by machine-learning tool p2rank with local probability and confidence. | String (e.g., Pocket 2: Pocket prob: 0.32%...) |
| **p2rank: pocket probability\*** | Ligand binding probability percentage assigned by p2rank models to the local surface pocket. | Float (e.g., 0.32) |

### **7\. Structural Contacts & Interactions (PDB & AlphaFold2)**

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **Intra-chain Hydrogen bond (PDB)** | Intra-chain hydrogen bonds observed in experimental PDB structures (with target residue and PDB ID). | String (e.g., E31-S41 (PDBs: 1F5Y)) |
| **Intra-chain Hydrogen bond (AlphaFold2)** | Intra-chain hydrogen bonds predicted from AlphaFold2 structures with Predicted Aligned Error (PAE) scores. | String (e.g., F32-I40 (PAE: 2.0)) |
| **Intra-chain Non-bonded interaction (PDB)** | Intra-chain non-covalent contacts (van der Waals, hydrophobic packing) from experimental PDB structures. | String (e.g., R26-Q33 (PDBs: 1F5Y)) |
| **Intra-chain Non-bonded interaction (AlphaFold2)** | Predicted intra-chain non-bonded contacts derived from AlphaFold2 structural models. | String (e.g., C27-Q33 (PAE: 5.5)) |
| **Intra-chain Disulfide bond (PDB)** | Experimental intra-chain covalent disulfide bridges identified in resolved PDB entries. | String (e.g., C27-C39 (PDBs: 1F5Y, 1LDL)) |
| **Intra-chain Disulfide bond (AlphaFold2)** | Predicted intra-chain disulfide bonds based on proximity in AlphaFold2 models. | String (e.g., C27-C39 (PAE: 5.0)) |
| **Intra-chain Salt bridge (PDB)** | Intra-chain electrostatic ionic salt bridges (e.g., Lys/Arg to Asp/Glu) resolved in PDB. | String (e.g., D25-K38 (PDBs: 1F5Y)) |
| **Intra-chain Salt bridge (AlphaFold2)** | Predicted intra-chain ionic salt bridges modeled in AlphaFold2 structures. | String (e.g., E208-K223 (PAE: 3.5)) |
| **Inter-chain Hydrogen bond (PDB)** | Hydrogen bonds formed across distinct polypeptide chains in multi-protein complexes. | String (e.g., D:F86-A:R375 (PDBs: 5OYL)) |
| **Inter-chain Non-bonded interaction (PDB)** | Non-covalent hydrophobic and van der Waals interactions across complex chain interfaces. | String (e.g., D:F86-A:Q31 (PDBs: 5OYL)) |
| **Inter-chain Disulfide bond (PDB)** | Inter-chain covalent disulfide linkage between separate subunits or binding partners. | String |
| **Inter-chain Salt bridge (PDB)** | Inter-chain ionic salt bridge interactions present at complex interfaces. | String (e.g., D:D90-A:K68 (PDBs: 5OYL)) |

### **8\. Protein Feature Enrichment Scores (PFES)**

The **Protein Feature Enrichment Score (PFES)** framework measures the localized statistical enrichment or depletion of genetic variants (such as pathogenic missense variants from ClinVar or benign variants from gnomAD) within specific structural and functional protein contexts.

| Feature (Column Name) | Description | Data Type & Example |
| :---- | :---- | :---- |
| **PFES** | Overall composite Protein Feature Enrichment Score combining multi-dimensional structural and functional annotations. | Float (e.g., \-4.34, 2.15) |
| **PFES\_Physicochemical** | Sub-score evaluating variant enrichment relative to amino acid physicochemical shifts (mass, polarity, hydropathy). | Float (e.g., 0.3196) |
| **PFES\_Structure** | Sub-score quantifying enrichment at structural microenvironments (secondary structures, burial depth, pLDDT). | Float (e.g., \-4.6631) |
| **PFES\_Domain** | Sub-score assessing variant clustering within specific UniProt structural and functional domain boundaries. | Float (e.g., 1.8539) |
| **PFES\_Function** | Sub-score reflecting variant enrichment at annotated active sites, binding pockets, and functional regions. | Float |
| **PFES\_Modification** | Sub-score measuring variation impact at post-translational modification (PTM) sites. | Float |
| **PFES\_PPI** | Sub-score assessing variant enrichment within Protein-Protein Interaction (PPI) interface surfaces. | Float (e.g., 3.5166) |
